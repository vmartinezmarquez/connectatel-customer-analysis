# Análisis de clientes de ConnectaTel

## Objetivo del proyecto
Analizar el comportamiento de los clientes de ConnectaTel mediante técnicas de análisis exploratorio de datos (EDA), limpieza de datos, segmentación y visualización, con el fin de identificar patrones de uso y generar recomendaciones comerciales.

---

## Datasets utilizados

- **users.csv** → Información demográfica y de registro de usuarios.
- **usage.csv** → Información histórica de llamadas y mensajes durante 2024.

---

## Etapas del análisis

1. Carga y exploración de datos
2. Limpieza de datos
3. Análisis exploratorio (EDA)
4. Detección de outliers
5. Segmentación de clientes
6. Insights ejecutivos

---

## Herramientas utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Hallazgos principales

- La mayoría de clientes pertenece al segmento de **Uso medio**
- El grupo demográfico dominante corresponde a **Adultos**
- Se identificaron usuarios de alto consumo (heavy users)
- Existen oportunidades comerciales para mejorar la diferenciación de planes

---

## Cómo ejecutar el proyecto

1. Descargar el notebook `.ipynb`
2. Abrirlo en **Jupyter Notebook** o **Google Colab**
3. Ejecutar las celdas en orden
4. Revisar análisis, visualizaciones y conclusiones

---

## Recomendaciones de negocio

- Fortalecer estrategias para usuarios de **Uso medio**
- Diseñar beneficios para **usuarios de Alto uso**
- Crear campañas orientadas a captar **usuarios jóvenes**
- Revisar la diferenciación entre planes actuales
